# Implementation-aware coverage (bounded bootstrap probes)

This is a **bounded local guard catalogue**, not a TS7 upstream conformance score. Existing `CompilationTests.cs` rows are bound to its exact Git blob and retained in their original xUnit tests. Their fourteen explicitly registered local inputs classify as **4 implemented / upstream NOT_RUN** and **10 SKIP (reason: UNIMPLEMENTED)** spanning seven distinct missing capabilities: function declarations, postfix updates, binary expressions, `@ts-ignore`, `any`, object literals and intrinsic `globalThis`.

The ten unsupported-feature xUnit tests **continue to run**, proving that the bootstrap rejects such inputs instead of silently accepting them. This success is **not** evidence that those features are implemented. The SKIP classification is maintained in a separate machine-readable compatibility-status report, not by disabling existing regressions or removing `--fail-skips on`. Neither this catalogue nor the 15,450 internal tests have verified mapping to the full TS7 executable-case denominator.

Run `node tools/implementation-coverage.ts --check` to fail closed on unregistered/moved guard inputs, changed source Git blob, changed reference pin, fabricated upstream mapping or invalid status/reason pairs. Use `--write` for intentional report updates; `--release` continues to fail while skips and unknown upstream expansion remain. `node --test tools/implementation-coverage.test.ts` covers these guards and verifies an implemented mismatch stays FAIL, never SKIP.

The validated machine-readable counts and stable per-probe identities are in [implementation-coverage.json](../testing/ts7/implementation-coverage.json), generated from [the registration](../../tests/implementation-coverage/registry.json). The **original compiler/reference acceptance remains NOT_RUN**, and 13,006 source fixtures/67,951 tracked assets must never be mistaken for an executable test denominator. Upstream skips, seven reference fatals, unexpanded source variants, helper-vector suites and the separate 29-case frozen cohort retain their own scope and status.

**This slice changes reporting, not language behavior:** new upstream acceptance = 0; removed SKIPs = 0; actual compiler implemented additions = 0. An ETA cannot yet be measured from one dated snapshot with no fixed, fully expanded upstream case denominator and no time-separated net completion samples. Future estimates must use stable case IDs and actual PASS deltas separately for scanner/parser/binder/checker/emit, including all remaining SKIPs and failures.
